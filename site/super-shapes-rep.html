Identity goals

💜 💖 Main goal 💖 IMAGINE WHAT'S POSSIBLE I AM AN EXPLORER 💖 Secondary goal 💖 DISCOVER IT FOR YOURSELF I AM A PROBLEM-SOLVING PROGRAMMER 💖 Message for girls 💖 Curiosity can change the world. 💖 Learning objective 💖 I can create and follow an algorithm. 💜

Introduction

💡 Introduce Linda Liukas, a programmer, author, and educator who creates fun and creative ways for children to explore computing. Explain that Linda believes computing can be explored through play, movement, imagination, and creation. Show some examples of her Playground activities, including physical activities that represent algorithms. Tell the girls: "Today, we are going to explore algorithms in a way inspired by Linda. We are going to become programmers without sitting in front of a computer." Remind the girls that an algorithm is a sequence of instructions for performing a task. 💡

Explanation and demonstration

👩‍🏫 Model the ideas live using the board. 1. Introduce the concept of an algorithm Write "algorithm" on the board and explain: "An algorithm is a set of instructions organized in the correct order to perform a task." Show a simple algorithm from everyday life, such as making a sandwich. Ask: What would happen if the instructions were in the wrong order? 2. Create a movement algorithm Use a simple sequence: Clap - Clap - Pat thighs - Turn → → → Do it together, then change the order of the movements. Ask: "Is it still the same algorithm?" 3. Introduce symbols Explain that programmers can use symbols to represent instructions. Draw on the board: → = move forward ○ = jump △ = turn ★ = clap Show how the symbols can be arranged in a sequence: START → → ○ → △ ★ → END Follow the sequence yourself. Then change one of the instructions and perform it again. Key message "Today, you are going to create your own algorithms using symbols, movement, and play. You will be creative programmers and problem solvers." 👩‍🏫

Main activities and plenary

🧩 Main Activities 1. Dance the Algorithm Explain that the "hand jive" is a simple, rhythmic dance that uses repetitive hand and body movements, such as clapping, clasping hands together, and slapping thighs. Teach the class this sequence: Clap - Clap - Slap thighs - Clap - Slap thighs → → → → Perform it together several times. Then, change the order of the movements and ask: "Is it still the same algorithm?" Challenge The girls work in pairs to create their own algorithm consisting of 3 to 5 movements. They can use actions such as: clapping; clasping hands together; slapping thighs; stomping; snapping fingers; touching shoulders. Each pair shows their algorithm to another pair, who must follow the instructions exactly. 2. Create a Playground Algorithm The girls work in pairs or small groups to create a simple path using paper, chalk, or a space on the ground. They create symbols to represent different instructions. For example: ➡️ move forward 🔵 jump 🟢 hop on one foot ⭐ turn around 😄 clap 🔺 spin Challenge Create a sequence of symbols that leads a person from START to FINISH. Then: Create → Follow → Test → Debug → Improve → → → → Swap algorithms with another group and follow their instructions exactly. Let's Revisit Linda — 5 minutes Show the photograph of Linda again. Ask: Who did we meet today? What does Linda do? Reinforce: "Linda Liukas is a programmer who helps children explore computing through play, creativity, and imagination. She has created ways for children to experience concepts like algorithms through movement, creation, and experimentation." Connect her work directly to the lesson: "Today, we learned about algorithms in a way inspired by Linda. We became programmers, created our own instructions, tested them, and discovered how to improve them." Guiding questions What makes an algorithm easy to follow? What happened when an algorithm didn't work? How did you solve the problem? What did you discover while experimenting? Reinforce "Programmers don't need to know everything before they start. They can be curious, try out an idea, test it, and figure out how to solve problems." Plenary Before finishing, ask the girls to complete these sentences out loud: Today I discovered... Today I solved... A good algorithm needs... I think Linda's ideas are... Connect with identity Remember the two identity goals: IMAGINE WHAT IS POSSIBLE DISCOVER IT FOR YOURSELF Invite the girls to reflect on how they acted as explorers and problem-solvers during the activity. 💜 Final message for the girls Before ending the class, close by reading this message aloud: "Linda Liukas was curious about discovering new ways to teach computing to children through play. Today, you were curious too. You created algorithms, experimented with them, and found solutions to the problems that arose. That means you were thinking like programmers—just like Linda! Remember that your curiosity can lead you to discover things that do not yet exist." 🧩
